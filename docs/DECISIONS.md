# Decisions

Choices made where the brief was silent or ambiguous. Newest last.

| #   | Decision                                                                                                                                                                                         | Why                                                                                                                                                            |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **Next.js 15.5** (not 16), React 19.2, Prisma 6.19, TypeScript 5.9, Zod 3.25, Tailwind 4                                                                                                         | Brief says "Next.js 15+". 15.5 is the mature line Auth.js v5 and the rest of the stack are proven on; Prisma 7 and TS 7 are new majors with breaking changes.  |
| 2   | **Auth.js v5 beta** with JWT sessions                                                                                                                                                            | Credentials provider requires JWT. A split edge-safe config (`src/lib/auth/config.ts`) keeps Prisma and argon2 out of middleware.                              |
| 3   | **@node-rs/argon2** for password hashing                                                                                                                                                         | Prebuilt binaries, no native compile step; argon2id with OWASP parameters.                                                                                     |
| 4   | Magic links only for **existing** accounts                                                                                                                                                       | Parents, applicants and staff are created by the school; no public sign-up surface.                                                                            |
| 5   | Fonts self-hosted from Fontsource files via `next/font/local`                                                                                                                                    | Works offline, no runtime call to Google, Latin subset only (perf).                                                                                            |
| 6   | `/_design` lives at `src/app/%5Fdesign`                                                                                                                                                          | App Router treats `_folders` as private; the URL-encoded underscore makes the route public.                                                                    |
| 7   | Rate limiting stored in Postgres (`RateLimitHit`)                                                                                                                                                | Works across server instances without adding Redis to a demo. Swap for Redis/Upstash at scale.                                                                 |
| 8   | Image captcha is SVG generated on the server; token = HMAC(answer, nonce) + expiry; single use                                                                                                   | No third-party dependency; answer never sent to the client.                                                                                                    |
| 9   | Mock gateway mirrors Razorpay conventions (`order                                                                                                                                                | payment` HMAC, webhook HMAC over raw body)                                                                                                                     | Downstream code is identical for mock and real gateways. |
| 10  | Webhook handler idempotency is two-layered: unique `(provider, eventId)` **and** unique `providerPaymentId`                                                                                      | A replayed event with a new id still can't double-credit.                                                                                                      |
| 11  | Registration fee is never put on the annual invoice                                                                                                                                              | It is collected at registration through its own order.                                                                                                         |
| 12  | Concessions apply in priority order on the _remaining_ amount; an exclusive concession only applies if nothing was applied before it and blocks everything after                                 | Deterministic and explainable line by line ("why is my discount ₹X?").                                                                                         |
| 13  | Late fee is recomputed absolutely each night and never lowered                                                                                                                                   | Idempotent job; a part-payment doesn't erase a fee that was already charged. Waiver is explicit, permissioned and audited.                                     |
| 14  | Advance rebate applies only to single-instalment plans due on/before the rebate date                                                                                                             | Matches "rebate if paid in full by date"; forfeited by the nightly job if unpaid by then.                                                                      |
| 15  | Refund policy defaults: new pupil 100 % of refundable heads before the session starts, 0 % after; existing pupil pro-rata unconsumed share minus one term (33.33 %) in lieu of < 90 days' notice | Configurable in Settings → Fees; sample values only.                                                                                                           |
| 16  | Announcement bar and events are **database-backed** (seeded from `content/*.json`)                                                                                                               | The brief asks for both "driven from content JSON" and "editable in content admin". The JSON is the seed and the fallback if the database is unreachable.      |
| 17  | Mock email/WhatsApp/SMS adapters don't store anything themselves; the shared notify layer writes the `Outbox` row for every channel and provider                                                 | One audit trail regardless of provider; the mock "inbox" is just the outbox.                                                                                   |
| 18  | The `frontend-design` and Impeccable skills referenced in the brief were not installed in the build environment                                                                                  | Design decisions were made directly and recorded in `docs/DESIGN_SYSTEM.md`.                                                                                   |
| 19  | Fonts self-hosted via plain `@font-face` (not `next/font`)                                                                                                                                       | `next/font` preloads every file of a family; preloading italics competed with the LCP image on mobile. Manual faces let us preload only the two upright files. |
| 20  | Enquiry drawer, Open House modal and mobile menu are code-split and mount on first use                                                                                                           | Keeps Radix Dialog, react-hook-form and Zod (~50 kB) out of every page's first load.                                                                           |
| 21  | Route transition only after client-side navigation                                                                                                                                               | A fade-in on first load delays LCP (Chrome ignores opacity-0 paints).                                                                                          |
| 22  | Honeypot field is accepted by the schema and silently "succeeds"                                                                                                                                 | Rejecting it with a validation error tells bots which field to leave empty.                                                                                    |
| 23  | All dates are formatted in IST with `@date-fns/tz`; date-only values are stored as UTC midnight                                                                                                  | Server and visitor timezones vary; the school's calendar doesn't. Financial-year boundaries are also computed in IST.                                          |
| 24  | E2E runs against its own Next server (`NEXT_DIST_DIR=.next-e2e`, port 3100, `CAPTCHA_PROVIDER=none`, `E2E=1` disables rate limiting)                                                             | Coexists with `pnpm dev`; the image captcha is covered by unit tests instead.                                                                                  |
| 25  | Fee pages show the next admissions year by default with a switch to the current year                                                                                                             | Families reading fee pages are mostly applying for next year.                                                                                                  |
| 26  | PDFs use built-in Helvetica/Times and print "Rs." instead of "₹"                                                                                                                                 | Standard PDF fonts lack the rupee glyph; avoids shipping TTFs.                                                                                                 |
| 27  | 360° viewer: Photo Sphere Viewer v5 with the Virtual Tour plugin in `renderMode: "2d"` and manual yaw/pitch links                                                                                | Works with any equirectangular image; hotspot positions live in `content/tour.json`.                                                                           |
